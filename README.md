# Calculator

As part of [The Odin Project](https://www.theodinproject.com/) curriculum, this project is a creation of a simple online calculator that is capable of the following operations:

* addition
* subtraction
* multiplication
* division

Other operations include using decimals in your equation, a clear, and delete button. As name suggest, the clear button let's you reset calculator back to zero including operator. Delete button is similar to the clear button excepts it'll remove the last number on screen. Plans to add keyboard support in future builds.

## Features

The goal of this project in it's simple and responsive design that appears and response to different screen sizes. This is designed with users in mind with it's large buttons and display window for ease of use. As stated earlier, plans for keyboard support will be added in the future.

To help meet these goals, this project use the following languages and other products:

* HTML5
* CSS3
* JavaScript
* CSS Flex
* Digital-7 Mono font by [Style-7](https://www.fontspace.com/digital-7-font-f7087)

### Note

This project was created with minimal use of AI, using it only for troubleshooting. Everything else was made by hand with some help from Google.
